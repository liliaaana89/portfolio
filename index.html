English · Search relevance

Rating a search result

Query: “How to filter only TCP packets in Wireshark”

Result: A page explaining the display filter tcp.flags.syn == 1.

Read the rating

Rating: Partially relevant. The result is about TCP display filters, but it shows only packets with the SYN flag set.

Better match: A result that gives the display filter tcp and explains where to enter it.

English · AI response evaluation

Checking technical accuracy

Prompt: “What are the three steps of a TCP handshake?”

Response: “The client sends SYN, the server sends ACK, and the client sends SYN-ACK.”

Read the evaluation

Assessment: Incorrect sequence. The server replies with SYN-ACK, and the client finishes with ACK.
